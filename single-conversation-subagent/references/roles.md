# ZCode 原生执行与复核角色

六个专用角色只在长任务自动编排；主对话对工作包子任务在成功 prepare 后按 `kind` 调用宿主 `Agent(subagent_type=...)`。MCP 只校验状态、资源与证据，不调度 Agent。标准/快速走 ZCode 内建流程，仅按需用默认/内建 Agent；只调查可按需用只读内建 `Explore`。用户明确点名时，可在自动流程外手动调用可用的专用角色，但仍遵守模式和授权范围，不切换模式、不触发 SCS 复核问答，也不替代正式复核或操作闸门。下表的中文名称就是 ZCode 派发 ID；模型由用户的 ZCode 角色配置固定或继承，调用不传模型覆盖、不改角色定义，也不用 `general-purpose` 冒充缺失角色。

| 子任务 kind | `subagent_type` | 模型绑定 | 默认租约 | 行为边界 |
| --- | --- | --- | --- | --- |
| `analyze` | `查询侦察员` | 固定 DeepSeek | 无 | 只读检索分析；返回结论、`file:line`、假设与建议 |
| `implement` | `实施工程师` | 继承当前模型 | 每个 scope 独占写租约 | 只改 `allowed_files`；只跑获准且写入范围合规的最小自检 |
| `test` | `测试验证员` | 固定 DeepSeek | 无 | 只跑指定验证命令，不改源码、配置、断言或验收 |
| `review`（`gpt`） | `固定审阅员` | 固定 GPT | 无 | 按确认路由独立只读复核；仅返回原始最终消息 |
| `review`（`inherit`） | `继承审阅员` | 继承当前模型 | 无 | 按确认路由独立只读复核；仅返回原始最终消息 |

`方案顾问`（固定 GPT）不是工作包子任务角色，只用于单独的可选只读方案指导。

## 执行角色契约

- 只由主对话派发；各角色不提问、不再委派、不启动外部审查、不修改工作包状态、项目记忆或最终验收。现有角色不可派发时如实报 `BLOCKED`；不伪造调用或结果。
- 不扩大父范围，不扩展网络、安装、提交、推送或设备权限。烧录、擦除仍须独立确认及操作闸门。测试产生文件时仅用获准输出路径，命令无法遵守范围则阻塞。
- `查询侦察员` 只用只读工具，不运行构建、测试、安装、烧录、迁移或 Git 写操作。`实施工程师` 仅修改 `allowed_files`，不改验收或重排无关文件；长任务的正式验证由 `测试验证员` 按已选范围运行，主对话核对证据。`测试验证员` 只运行指定命令，报告环境、退出码、通过/失败数和日志来源，不用未选测试填 PASS。
- 主对话持久化证据；角色返回关键观察、日志出处或现成证据路径，不主动写证据文件到 `allowed_files` 以外。需日志文件时由主对话安排合规的输出并登记；验证命令不得借日志重定向扩大写权限。原生审阅员与 `方案顾问` 全程不落盘。
- 报告自己启动的进程是否停止、设备是否释放；在实际静止后由主对话结束 attempt。非 implement 无默认文件租约，不假设有共享读保护。

执行角色的最终消息用有界文本或 JSON（建议 ≤1–2 KB，不贴全量日志），至少包含以下字段：

```json
{
  "status": "PASS|FAIL|BLOCKED|NOT_RUN|SUBSTITUTED",
  "role": "analyze|implement|test",
  "actions": ["实际动作"],
  "changed_files": ["仅 implement，项目相对路径"],
  "commands": [{"command": "...", "exit_code": 0, "evidence": "<已有证据路径或 null>"}],
  "evidence": ["<已有证据路径或 file:line>"],
  "first_error": "首个异常或 null",
  "remaining": ["剩余问题/风险"],
  "resources": {"processes_stopped": true, "devices_released": [], "notes": ""}
}
```

`PASS` = 满足约定并有可核验证据，不等于最终验收；`FAIL` = 已执行但未满足；`BLOCKED` = 前置不足；`NOT_RUN` = 未执行；`SUBSTITUTED` = 经主对话同意的替代结果。不做测试与只记录方法均不标 PASS。

通用提示模板（按表派角色，具体列出允许和禁止项）：

```text
你是 WP-<id> / R<n> / attempt <id> 的 <role>。不提问、不再委派、不修改状态或验收。
工作目录与基线：<cwd、commit/版本/现状>；目标与验收：<...>。
允许读取：<...>；允许写入：<...，非实施者不得修改项目，实施者仅 allowed_files>。
允许命令/设备：<逐项；侦察者仅只读，实施者仅最小自检，验证者仅已选验证>。
返回：按执行角色 schema；侦察者附 file:line，实施者附改动列表，验证者附退出码和通过/失败数。
未执行项标 NOT_RUN；不得另写证据文件、不贴全量日志。缺条件时说明并阻塞。
```

## 只读方案顾问（可选）

长任务开工前可建议一次指导；用户同意后由主对话单独调用 `Agent(subagent_type="方案顾问")`（固定 GPT），至多一次。输入有界目标、计划改动、风险、约束、验证和回滚。只读、不落盘、不运行验证、不再委派；只给建议，不出正式判定。主对话保存原始结果；它不参与 `review_route`、不写正式复核证据、不替代包级、收尾或操作预审。拒绝或不可用时跳过，不改派正式审阅员，也不解除复核闸门。

## 原生只读审阅员

用户选择 `review_route=gpt` → `Agent(subagent_type="固定审阅员")`（固定 GPT）；`review_route=inherit` → `Agent(subagent_type="继承审阅员")`（`model: inherit`）。`gpt`、`inherit` 是不变的协议值，不是派发 ID。已选路由用于 `packages` 包级复核、收尾与操作预审，不因不可用自动换模型/角色；两者均可派发时推荐 `gpt`，仍须用户确认。

- 只由主对话通过 `Agent` 派发，是不同于执行角色的独立子 Agent。不修改文件、不写证据、不构建/测试/烧录、不碰串口或板卡、不再委派。提示词仅允许规定范围内的只读观察；不加载外部复核技能或工具。
- 主对话准备有界 diff / 哈希、可读路径、明确基线、目标、验收及证据索引。包级附工作包/修订、prepare 的 `review_subject` 和非 review 结果；操作附 `operation_digest`、精确命令、作用面、备份和回滚。若重要输入无法观察或被截断，Reviewer 报明限制，不应给 ACCEPT。
- 正式复核返回有界逐项意见和恰好一行 `结论: ACCEPT` 或 `结论: REJECT`。主对话保存实际 Agent 原始最终消息，不改写、不补结论，用实际宿主完成回执记录 `agent_id`；证据的 `agent_type` 用该审阅员的中文派发 ID，模型仅据宿主可观测的 `provider/model`，否则 `unobserved`。
- 仅实际完成且有唯一一致结论、证据及当前绑定才可记正式判定。无角色、超时、身份或消息缺失、结论不唯一均不能 PASS / APPROVED；不能由主对话自己复核替代。收尾失败或 REJECT 如实报告；包级按新 attempt 重审；操作按闸门处理。
- manifest 与回执字段见 [MCP 用法](mcp.md)；即使复核 ACCEPT，仍由主对话验收。
