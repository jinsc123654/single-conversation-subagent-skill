# 单对话 subagent：两级协作协议

主对话是唯一协调/验收层，负责目标、决策、阶段记忆、拆分、调度和汇总；子 Agent 只分析/实现/测试，不再委派。主对话不承载执行日志。

## 开场四选一

每个新任务先问一次，包括直接命令；不得按大小/类型或时间紧跳过，同一任务追问不重复问。唯一例外：“不用问，直接做”→按快速处理开始；实际需要标准执行/长任务仍问验证范围。

1. **快速处理**：主对话直接做，不启子 Agent。
2. **标准执行**：先问验证范围，再给工作包/计划，然后实现和验证。
3. **长任务**：分阶段，计划前问验证范围，使用执行子 Agent。
4. **只调查**：不改文件；范围大时可派只读分析子 Agent。

只标一个推荐项并默认勾选，拿不准推荐标准执行；推荐不改变目标，也不免除提问。快速处理/只调查不做验证范围多选。

**三问超时统一**：只有用户明确不选（跳过/取消）或客户端报告 15 秒倒计时结束，才按各问推荐/默认继续；等待期间不落默认值，不重复追问。真正倒计时由客户端实现。

推荐：纯问答/搜索/小改/简单 Excel/快速查询→快速处理；多文件实现/构建测试→标准执行；全量回归/烧录/稳定性→长任务；只读定位/方案对比→只调查。

## 验证范围（标准执行 / 长任务）

每个新任务问一次，只给一个推荐路径：**快速冒烟（本轮）+ 定向回归（收尾）**。其他选项不标推荐/默认。

- 快速冒烟：本轮，2 min，只读。
- 定向回归：收尾，15 min，板卡 A。
- 全量回归：收尾，2 h，板卡 A。
- 长时间稳定性：收尾，8 h，独占板卡/串口。
- 烧录/擦除：按需，单独确认。
- 不做测试 / 不做测试但记录方法：二选一，且与测试操作互斥。

定向/全量回归和稳定性收尾执行，不每轮重复。“不做测试”标 `NOT_RUN`；“记录方法”只将命令/环境/预期结果写入 `AGENT_COORDINATION.md`，不标 `PASS`。未选长耗时操作不执行；新增操作走新修订。超时按唯一推荐路径。

## Codex 审查联动（仅标准执行 / 长任务）

- **发起条件**：注册三态：本会话技能列表确认已装 `codex-review` 才问；确定未装跳过（不算漏问）；未知（列表不可得/压缩恢复）可查 `~/.agents/skills/codex-review/SKILL.md` 或项目 `.zcode/skills/codex-review/SKILL.md` 辅助确认，仍未知按未装，不声明已装。用户已明确要求 Codex 审查→不问，直接按该技能执行，不被默认“不使用”覆盖。

- **问句**：验证范围问完紧接着问“收尾是否用 Codex 独立审查？”两项：“不使用”（唯一推荐/默认勾选）；“使用”（收尾按 `codex-review` 只读独立审查，逐项判定 + ACCEPT/REJECT 落档）。
- **超时**：按“不使用”。

- **执行与去重**：迟到回复绑定提问 ID/工作包/修订；先核对状态，只调整未执行部分并报告已发生操作。选“使用”且未收尾→收尾执行；已收尾→`NOT_RUN`，补审走新修订。同工作包/修订只审一次；审查者不再启动新 Codex 会话。引用/讨论技能名≠调用。

## 工作流程

1. 依次完成适用提问：四选一→验证范围→Codex 联动。
2. 主对话定义工作包：目标、验收、目录、基线、允许/禁止操作、子 Agent 类型、证据要求。
3. 主对话读写默认记忆：`docs/agent/AGENT_PROJECT.md`、`docs/agent/AGENT_COORDINATION.md`、`docs/agent/evidence/`。
4. 拆分子任务；独立只读可并行，同文件/板卡/串口/烧录串行。
5. 用 `Agent` 工具创建执行子 Agent，名称按任务；提示含子任务、范围、禁止、检查、证据路径、“不得再委派”。
6. 子 Agent 落证据；只回传状态、动作、证据路径、首异常、剩余问题、资源释放，不贴原始日志。
7. 主对话核对证据，区分 `PASS/FAIL/BLOCKED/NOT_RUN/SUBSTITUTED`，无证据不标 `PASS`，更新协作记录。
8. 主对话独立验收 diff/日志/测试/产物；只有主对话更新验收结论。
9. 同一工作包继续在主对话；压缩/重启时从 `AGENT_COORDINATION.md` 恢复。

## 上下文预算与补救

- 三级记忆：主对话摘要 → `AGENT_COORDINATION.md` 阶段记忆 → `docs/agent/evidence/` 完整日志。
- 子 Agent 回传有界（建议 ≤1–2 KB）；主对话只读关键证据，不读全量日志。
- 每个工作包/阶段结束写 handoff；主对话接近 60%–70% 上下文或压缩时，新开会话，从文件恢复。
- 长测试后台化：子 Agent 返回 PID/日志/状态/停止方式后结束，主对话按检查点查询。
- 子 Agent 上下文过大时停止并新建，传摘要和证据路径。
- 同一对话内保持系统提示/AGENTS/skill 稳定；规则变更新会话生效。

## 硬边界

1. 只有主对话创建子 Agent；子 Agent 不继续委派。
2. 子任务范围 ≤ 父工作包；不授予文件/网络/提交/推送/烧录权限。
3. 调查只读；测试不改源码/不重建/不换镜像；实现只改允许文件。
4. 同文件/同设备串行；不重复提交；停止确认终态后释放资源。
5. 编译成功、任务结束、现场恢复、根因修复分别报告；最终由主对话验收。
6. 子 Agent 不改顶层规划/记忆文件/验收/安全策略；冲突回主对话。
7. 不伪造 ID/状态/证据；取不到 `agentId` 记“ID 不可得”。
8. 无法创建真实子 Agent → `BLOCKED`，不静默降级；只有用户授权才单级回退。
9. 回传有界；长测试后台化；接近上下文上限写 handoff 并新会话。
10. 不记录密钥/Cookie/私有 URL/原始推理；用户明确指令优先。
11. 三问均遵守上文“三问超时统一”；各问默认见对应段落。
12. 每个新任务都必须发起四选一；不得按任务大小/类型自动跳过。唯一例外是用户明确说“不用问，直接做”。

## 子 Agent 启动模板

```text
Agent(
  description="<任务>子 Agent",
  subagent_type="general-purpose",
  run_in_background=false,
  prompt="""
你是工作包 WP-<id> / R<n> 的执行子 Agent，角色：<分析/实现/测试>。
主对话负责目标、阶段记忆、调度和验收；你不创建下一级 Agent。
工作目录：<cwd>
子任务：<...>
输入上下文：<...>
允许范围：<文件/设备/操作>
禁止事项：<...>
基线：<...>
检查方法：<...>
证据写入：<项目根>/docs/agent/evidence/WP-<id>/R<n>/<subtask-id>/
最终消息：实际动作、逐项结果、证据路径、首异常、剩余问题、资源释放。
"""
)
```

模型：子 Agent 默认继承主对话的 provider/model，模板不写死模型。若某个 agent 定义（如插件的 visual-judge）固定了 `model:`，先改为继承或按用户指定覆盖，再派发。

## 完整协议

标准执行/长任务加载本技能；快速处理/只调查只用 AGENTS 规则，不加载技能正文与完整协议。需要角色细节、字段、异常处理和桥接模式对比时读 `references/protocol.md`。
