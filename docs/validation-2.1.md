## 本次完成

1. 在 2.0 的官方 MCP SDK 2.3.0 / stdio / SQLite 服务上新增 Obsidian 项目视图，共 **1 个服务、16 个工具、2 类资源**。没有创建第二个 MCP 服务，也没有修改任一客户端的注册配置。
2. docs-root 可作为独立 Obsidian 库，`agent/acceptance` 提供不依赖插件的项目、工作包、修订、证据视图。保留手工批注和已有库配置；生成区冲突停止；中断可以重试恢复。仅对子任务报告使用“已报告通过”，不伪造主对话的最终验收。
3. SQLite schema 1→2 迁移保留旧数据，只保存实际当前修订；以后的修订真实留档，不虚构旧历史。回退 2.0 需要升级前数据库备份，不能用旧服务直接打开 schema 2。
4. 新增独立可选 PyQt5 管理器，参照指定本机工具的主题与异步取数方式：项目添加/发现、文件夹浏览、Obsidian 跳转、工作包/事件查看、连接自检、受管文件清单、刷新/初始化和可恢复归档。MCP 安装器与 wheel 均不依赖 Qt，不强制安装管理器。

管理器的数据库查看不迁移、查询不改变业务数据；可能由 SQLite 自身维护 WAL/SHM。自检显式启动短期 stdio 实例，结束即退出；不等同于已观察到宿主连接，也不提供虚假的“在线”状态。归档受 SQLite 写事务协调，保留整个视图内手工内容，不删除状态、记忆、证据和库配置；外部编辑器并不受该锁限制。
